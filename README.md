# KunAI

Kundalik vazifalarni rejalashtirish uchun brauzerda ishlaydigan shaxsiy planner.

## Hozirgi imkoniyatlar

- Vazifa nomi, ustuvorligi va bajarish muddatini kiritish.
- Vazifani bajarilgan yoki faol holatga o‘tkazish.
- Barcha, faol va bajarilgan vazifalarni filtrlash.
- Muddati o‘tgan, bajarilmagan vazifalarni alohida hisoblash.
- Vazifalarni bajarilish holati, ustuvorlik va muddat bo‘yicha tartiblash.
- Bajarilgan vazifalarni tasdiq bilan tozalash.
- Ma’lumotlarni shu brauzer qurilmasidagi `localStorage` da saqlash.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali joylashtiring. Build vositasi va API kaliti kerak emas.

## Saqlash chegarasi

Hozircha akkaunt, server bazasi, qurilmalararo sinxronlash va AI rejalashtirish ulanmagan. Brauzer ma’lumotlari tozalansa, lokal vazifalar ham yo‘qolishi mumkin.

## Keyingi bosqich

Vazifalarni eksport/import qilish, takrorlanuvchi vazifalar, haftalik ko‘rinish va xavfsiz bulut sinxronlash.
